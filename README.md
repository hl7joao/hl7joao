## 📌 Featured project: FaithfulMed (Break Through Tech AI Studio × Google)

**[FaithfulMed](https://github.com/Break-Through-Tech/Google-2D-faithfulmed-a-multi-agent-system-for-faithful-patient-friendly-medical-explanations)** is a multi-agent system built with Google's Agent Development Kit and Gemini. It rewrites clinical text into plain language at an 8th-grade reading level without changing the facts.

**My role as a Break Through Tech Fellow:**
- Owned the pipeline architecture: what each agent receives and passes on, plus a bounded fix loop after the final check.
- Built the **FinalCheck agent**, with number and negation guards that need no model (88 tests), and the **Readability agent** (26 tests).
- Built the glossary lookup over **1,012 MedlinePlus health topics and 2,868 alternate names** (19 tests).
- Found in my data exploration that the glossary explains **13 of 13** common conditions but **0 of 5** medicines. That became a safety rule: keep an unexplained term as written instead of inventing a definition.
- Reviewed teammates' pull requests end to end and caught 4 bugs before merge, including two that let a dropped "no" pass unflagged.

**Tools:** Python, Google ADK, Gemini API, ChromaDB, textstat, Jupyter
